# **NumPy Exercises — Hints & Solutions**

This repository contains a collection of **NumPy practice exercises** designed for learning, self-testing, and revision.  
It includes automatically generated versions of the exercises in:

- **Jupyter Notebook** format  
- **Markdown** format  
- **Markdown with hints**  
- **Markdown with full solutions**  
- **Markdown with hints + solutions**

---

## **📂 Project Structure**

```
STUDY NUMPY/
│
├── source/
│   ├── exercises100.ktx
│   └── headers.ktx
│
├── 100_Numpy_exercises.ipynb
├── 100_Numpy_random.ipynb
├── 100_Numpy_exercises.md
├── 100_Numpy_exercises_with_hints.md
├── 100_Numpy_exercises_with_solutions.md
├── 100_Numpy_exercises_with_hints_with_solutions.md
│
├── generators.py
├── initialise.py
└── numpy_tuto.py
```

---

## **🛠️ How to Generate the Exercises**

Run the main initializer:

```bash
python initialise.py
```

Or run the generator script manually:

```bash
python generators.py
```
